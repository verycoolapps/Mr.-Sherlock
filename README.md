## 🏗️ THE INVESTIGATION PROTOCOL

Every investigation follows a **systematic 7-phase methodology**:

```
PHASE 1: CASE INTAKE          → Understand objective, classify investigation
         ↓
PHASE 2: HYPOTHESIS           → Generate multiple competing theories
         ↓
PHASE 3: EVIDENCE COLLECTION  → Gather from prioritized source hierarchy
         ↓
PHASE 4: FORENSIC ANALYSIS    → Pattern detection, contradiction identification
         ↓
PHASE 5: CONNECTION DISCOVERY → Map relationships, reveal hidden connections
         ↓
PHASE 6: FACT VERIFICATION    → Challenge findings, cross-verify
         ↓
PHASE 7: CASE CONCLUSION      → Evidence-based verdict with confidence levels
```

Every finding is classified into 6 confidence categories:
- ✓ **VERIFIED FACT**
- ✓ **STRONGLY SUPPORTED**
- ? **PLAUSIBLE**
- ✗ **UNVERIFIED**
- ✗ **CONTRADICTED**
- ? **UNKNOWN**

## 🏗️ PROTOKOL INVESTIGASI

Setiap investigasi mengikuti **metodologi 7-fase sistematis**:

```
FASE 1: CASE INTAKE           → Pahami tujuan, klasifikasikan investigasi
         ↓
FASE 2: HIPOTESIS             → Hasilkan beberapa teori bersaing
         ↓
FASE 3: PENGUMPULAN BUKTI     → Kumpulkan dari hierarki sumber prioritas
         ↓
FASE 4: ANALISIS FORENSIK     → Deteksi pola, identifikasi kontradiksi
         ↓
FASE 5: PENEMUAN KONEKSI      → Peta hubungan, ungkap koneksi tersembunyi
         ↓
FASE 6: VERIFIKASI FAKTA      → Tantang temuan, verifikasi silang
         ↓
FASE 7: KESIMPULAN KASUS      → Vonis berbasis bukti dengan tingkat kepercayaan
```

Setiap temuan diklasifikasikan ke dalam 6 kategori kepercayaan:
- ✓ **FAKTA TERVERIFIKASI**
- ✓ **DIDUKUNG KUAT**
- ? **MASUK AKAL**
- ✗ **TIDAK TERVERIFIKASI**
- ✗ **BERTENTANGAN**
- ? **TIDAK DIKETAHUI**
